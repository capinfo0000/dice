# 🎲 チンチロ（飲みゲー）

1台のスマホをみんなで回して遊ぶ、チンチロ（チンチロリン）の飲みゲーWebアプリです。
親・子の区別はなく、**全員が振って一番強い役のプレイヤーが勝ち**。
そして **最下位（一番弱い役）の人が、勝者の役の倍率ぶんだけ飲む**。

サーバーは静的配信だけ。ゲームはすべてブラウザ内（ローカル）で動きます。

## 起動方法

```bash
npm install
npm start
```

ブラウザで <http://localhost:3000> を開くだけ。
（`public/index.html` を直接開いても動きます）

## 遊び方

1. 下のタブでプレイヤーを追加・名前変更（タブをタップで改名、× で削除、＋ で追加）
2. 右上のボタンで **3チロ / 4チロ** を切替
3. 中央の鉢（またはボタン）をタップして **サイコロを振る**
   - 役なしなら最大3回まで振り直し（上のドットが回数）
4. 「次へ」で次のプレイヤーへ。全員が振り終えると結果発表
5. 一番強い役が勝ち、**最下位が勝者の役の倍率ぶん飲む**
6. 最下位が同点なら **サドンデス（一振り）** で飲む人を決定
7. 「もう一局」で次のラウンドへ

## 設定（⚙）

右上の⚙から「止め方」を全員共通で切り替えられます（設定はブラウザに保存）。

- **役どめ ON**（既定）… 役が出たら自動で確定。役なしの間だけ振り直す。
- **役どめ OFF**（手動）… 役が出ても最大3回まで自分で振り直せる。
  「この役で止める／もう一回振る」を選んで確定する。
- **456サイコロ**… ONにすると 4・5・6 しか出ないイカサマ賽になる。
  シゴロやゾロ目が出やすい（モード表示が「3チロ・456」になる）。

※ 振り直しは毎回サイコロ全部を振り直すため、**最後に振った目だけが有効**（前の投の目は消える）です。
※ ヒフミ（1・2・3）は振り直しなしで即確定し、次のプレイヤーへ進みます。

## チョンボ

振るたびに **約1%** の確率でチョンボ（サイコロが鉢から飛び出す大失敗）が発生します。
チョンボを出した人は **即負け**。罰として2杯飲み、「やり直し」で同じメンバーのまま局を振り直します。

## モード

| モード | サイコロ | 振り直し | 判定 |
| --- | --- | --- | --- |
| 3チロ | 3個 | 役なしなら最大3回 | 3個で判定 |
| 4チロ | 4個 | 1振りのみ | 4個のうち最強の3個で判定 |

## 役と強さ（＝飲む杯数）

| 役 | 出目 | 配当 |
| --- | --- | --- |
| ピンゾロ | 1・1・1 | ×5 |
| アラシ（ゾロ目） | 同じ目3つ（数字が大きいほど強い） | ×3 |
| シゴロ | 4・5・6 | ×2 |
| 出目 | ペア＋1つ（残り1つの目が大きいほど強い） | ×1 |
| 役なし | 3回振っても役が出ない（ションベン） | 負け |
| ヒフミ | 1・2・3 | 負け役 |

## 構成

- `chinchiro.js` … 役判定・比較・精算のロジック（ブラウザ／Node 両対応）
- `public/` … フロントエンド（HTML / CSS / ゲーム本体 client.js）
- `server.js` … 静的配信サーバー（Express）
- `test/chinchiro.test.js` … ロジックのテスト（`npm test`）
