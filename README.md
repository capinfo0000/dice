# 🎲 チンチロ オンライン対戦

Node.js + Socket.IO で動く、リアルタイム対戦のチンチロ（チンチロリン）Webアプリです。
親・子の区別はなく、**全員が振って一番強い役のプレイヤーが勝ち**というシンプルなルール。

飲みゲー仕様：**最下位（一番弱い役）の人が、勝者の役の倍率ぶんだけ飲む**。
結果は大きなバナーで「🍺 ○○ が N杯 飲む！」と表示されます。
最下位が同点（複数人）になったら、その人たちだけで**サドンデス（一振り）**して飲む人を決めます（決着まで繰り返し）。

同じ端末でもブラウザのタブを増やせば、人数分のプレイヤーで対戦できます。

## 起動方法

```bash
npm install
npm start
```

起動したらブラウザで <http://localhost:3000> を開きます。
2人以上で遊ぶには、タブ（または別の端末）を増やしてそれぞれ参加してください。

## 遊び方

1. 名前を入れて「参加する」
2. 2人以上が集まり、全員が「準備OK」を押すとラウンド開始
3. 自分の手番になったら、**深いお皿をタップ**してサイコロを振る（落下音とともに転がり、一斉に止まる）
4. 全員が振り終えると、一番強い役の人が勝ち
5. 「準備OK」で次の局へ

手番は順番に回るので、後に振る人は先に振った人の出目・役を見てから振れます。

## モード（ロビー／局終了時に切替）

| モード | サイコロ | 振り直し | 判定 |
| --- | --- | --- | --- |
| 3チロ | 3個 | 役なしなら最大3回 | 3個で判定 |
| 4チロ | 4個 | 1振りのみ | 4個のうち最強の3個で判定 |

## 役と強さ（強い順）

| 役 | 出目 | 配当 |
| --- | --- | --- |
| ピンゾロ | 1・1・1 | ×5 |
| アラシ（ゾロ目） | 同じ目3つ（数字が大きいほど強い） | ×3 |
| シゴロ | 4・5・6 | ×2 |
| 出目 | ペア＋1つ（残り1つの目が大きいほど強い） | ×1 |
| 役なし | 3回振っても役が出ない（ションベン） | 負け |
| ヒフミ | 1・2・3 | 負け役 |

## 構成

- `chinchiro.js` … 役判定・比較・精算のロジック（ブラウザ／Node 両対応）
- `server.js` … Socket.IO サーバー（テーブル進行管理）
- `public/` … フロントエンド（HTML / CSS / クライアントJS）
- `test/chinchiro.test.js` … ロジックのテスト（`npm test`）
